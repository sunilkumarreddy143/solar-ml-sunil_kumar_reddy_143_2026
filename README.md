# ☀️ Solar Energy Production Prediction (Machine Learning Project)

## 📌 Project Overview
This project focuses on predicting solar energy production using multiple regression models.  
Different machine learning algorithms were trained, evaluated, and compared to identify the best-performing model for accurate solar energy forecasting.

The goal is to build a reliable regression model that can help in energy planning and renewable energy optimization.

---

## 🎯 Objective
- Analyze solar energy generation data  
- Perform data preprocessing and feature analysis  
- Train multiple regression models  
- Compare performance using evaluation metrics  
- Select the best-performing model  

---

## 📊 Dataset Description
The dataset contains solar energy production and related system parameters.  
Data preprocessing steps included:

- Handling missing values  
- Feature selection  
- Exploratory Data Analysis (EDA)  
- Train-test split  

---

## ⚙️ Models Implemented
The following regression models were trained and evaluated:

- Linear Regression  
- Random Forest Regressor  
- Gradient Boosting Regressor  
- XGBoost Regressor  

Each model was evaluated using standard regression metrics.

---

## 📈 Final Model Performance

The selected final model achieved the following performance on the test dataset:

- **RMSE:** 0.00577  
- **MAE:** 0.00331  
- **R² Score:** 0.99993  

The model demonstrates extremely high predictive accuracy with minimal error.

---

## 📊 Evaluation Metrics Used
- RMSE (Root Mean Squared Error)  
- MAE (Mean Absolute Error)  
- R² Score  

These metrics were used to compare model performance and select the optimal regression model.
